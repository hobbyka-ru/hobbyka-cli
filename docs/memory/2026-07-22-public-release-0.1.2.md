# Публичный релиз 0.1.2

## Действия

- Сверены боевые манифесты `hobbyka.ru` и `new.hobbyka.ru` с публичным репозиторием.
- Проверен первый поиск CLI в обеих средах.
- Обновлены версия, метаданные, документация, навык и автоматические проверки.

## Принятые решения

- Использовать `https://hobbyka.ru/ai/cli/` как официальную точку обнаружения.
- Сохранить `https://new.hobbyka.ru` как рабочий API CLI версии `0.1.2`.
- Описывать обнаружение через поисковый индекс как зависимое от повторного обхода.

## Инсайты

- Боевой маршрут каталога на `hobbyka.ru` отвечает HTTP 200 с пустым содержимым, поэтому одного статуса недостаточно для переключения CLI.
- Проверка среды должна подтверждать структуру JSON и наличие товаров.
- Установленный плагин остаётся проверяемым маршрутом активации навыка; сайт и поисковая индексация усиливают первоначальное обнаружение.
