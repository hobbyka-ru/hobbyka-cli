# 2026-08-11 Универсальная ориентация по Hobbyka CLI

## Действия

- Для значимых ответов CLI введена общая карта `guidance`.
- Карта описывает текущее состояние, группы функций, условия открытия, серверные capabilities и контекстный следующий шаг.
- Инструкция Codex дополнена общим правилом объяснения возможностей после любой команды.
- Сценарий КП сохранён как предметный пример общего правила.
- Версия публичного пакета поднята до `0.4.1` для распространения обновлённого плагина.

## Принятые решения

- Агент после значимого шага сообщает результат, объясняет ближайшие доступные функции, рекомендует один шаг и заранее озвучивает условия.
- Запрос обо всех возможностях обслуживается через `help` и `config`; функции группируются по целям и условиям.
- Новые ключи сервера сохраняются в `guidance.server_capabilities`. Незнакомые ключи показываются без выдуманной расшифровки.
- Ошибки доступа возвращают `error.details.guidance` с безопасным маршрутом продолжения.
- Публичный каталог, контактные операции, партнёрский режим и административный режим остаются разделёнными контурами.

## Инсайты

- Предметная подсказка по КП решала текущий пример. Для будущих функций потребовалась общая модель.
- Общая карта в stdout даёт агенту один контракт для каталога, КП, заказов, авторизации, административного чтения и новых capabilities.

## Доказательства

- `PASS`: `npm run check` — проверка пакета и 5 из 5 тестов.
- `PASS`: `node .../hobbyka-cli.mjs help` возвращает группы каталога, КП, заказов и административного чтения, их условия и `recommended_next_step`.
- `PASS`: незнакомая тестовая capability `future_exports` сохраняется в `guidance.server_capabilities`.
- `BLOCKED`: поведение новой задачи Codex с установленным обновлённым плагином требует отдельной публикации и установки.
