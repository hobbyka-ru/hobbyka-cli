# Запрос материалов для проектирования через CLI

## Решение

- Команда `materials request --stdin` отправляет стандартную форму Hobbyka №19 через публичный AI API.
- Обязательные данные совпадают с формой сайта: товар, ФИО, телефон, email и согласие на обработку персональных данных. Компания и комментарий остаются необязательными.
- Перед отправкой агент объясняет цель передачи данных и получает явное согласие пользователя.
- Сервер добавляет в комментарий пометку `Отправлено из Codex / Hobbyka CLI`, создаёт результат формы и запускает штатные CRM, почтовое событие и уведомление менеджеру.
- Контактные значения передаются через stdin, не сохраняются в состоянии CLI и не возвращаются в ответе.
- `Idempotency-Key` защищает менеджера от повторной заявки при повторе команды.

## Проверка

- `npm run check` проверяет обязательное согласие, передачу формы, ключ идемпотентности и отсутствие контактов в stdout/stderr.
- Production-проверка требует одной явно помеченной тестовой заявки и подтверждения её получения менеджером.
