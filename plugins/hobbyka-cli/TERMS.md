# Условия использования

CLI предназначен для подбора товаров Hobbyka и подготовки коммерческих предложений. Цены, скидки и расчёты определяются сервером Hobbyka. Результат подбора нужно проверить перед заказом.

Локальный визуальный поиск использует SigLIP2-L. Веса модели доступны по лицензии Apache-2.0 и не входят в CLI. Визуальное совпадение является результатом модели, а не гарантией идентичности товара.

Запрещено обходить контактный шлюз, автоматические ограничения запросов или использовать CLI для массовой нежелательной рассылки и иных противоправных действий.

Основные условия использования сайта: https://hobbyka.ru/
