# Конфиденциальность

CLI отправляет в Hobbyka поисковые параметры, идентификаторы выбранных товаров и, после явного предоставления, компанию и телефон либо email. Передача выполняется по HTTPS.

При локальном поиске по изображению исходный файл обрабатывается DINOv3 на компьютере пользователя и не передаётся в Hobbyka. Команда построения индекса скачивает публичные фотографии товаров. После уверенного совпадения CLI передаёт серверу только ID товара для получения актуальной карточки.

Контакт отправляется отдельной командой через стандартный ввод. В локальном состоянии сохраняются только серверный токен, срок его действия и признаки наличия полей; файл создаётся с правами доступа `0600`. CLI не печатает контактные значения, токен или заголовок авторизации.

Удалить локальный токен можно командой `contacts clear`. Серверное хранение и удаление контактов регулируются политикой конфиденциальности Hobbyka: https://hobbyka.ru/politika-konfidentsialnosti/
