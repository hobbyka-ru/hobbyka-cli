# Hobbyka CLI

Работать с Hobbyka только через `scripts/hobbyka-cli.mjs`. Не обращаться к API или MCP напрямую и не придумывать цены, скидки либо характеристики.

1. Выполнить первый поиск без контактов: `node scripts/hobbyka-cli.mjs search --query "..." --limit 10`.
2. Показать результат и сообщить владельцу, что для продолжения нужны компания и телефон либо email.
3. После согласия передать контакт CLI через стандартный ввод: `node scripts/hobbyka-cli.mjs contacts set --stdin`. Не помещать контакт в аргументы процесса, журналы или итоговый ответ.
4. Продолжить поиск, открыть карточки нужных товаров и сузить выбор. Считать изображения из поля `images` частью данных для визуального сравнения.
5. Перед созданием КП подтвердить идентификаторы и количества. Выполнить `node scripts/hobbyka-cli.mjs offer create --items "123:2,456:1"`.

CLI сам блокирует второй рабочий запрос без зарегистрированного контакта. Если он вернул `contact_required`, запросить недостающие данные и не обходить блокировку.

Параметр `--recommendation-profile <id>` зарезервирован для будущих служебных рекомендаций Hobbyka. Он не должен заменять или ослаблять явные требования пользователя.

Для test/dev задать `HOBBYKA_BASE_URL=https://dev.hobbyka.ru`. В штатной установке адрес production уже задан CLI.
