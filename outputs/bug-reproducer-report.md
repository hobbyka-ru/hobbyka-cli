## Root cause

Публичный пакет версии 0.7.1 заявлял зависимость от удалённого MCP и направлял к нему агентов, хотя доступного сервера нет.

## Applied fix

Убраны объявление и файл MCP, зависимость из openai.yaml и ложные обещания из навыка и документации. Синхронно повышена версия CLI и плагина до 0.7.2.

**Why this is causal:** После установки плагин больше не пытается подключить несуществующий сервер; каталог продолжает работать через существующий CLI.
