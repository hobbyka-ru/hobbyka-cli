# Hobbyka CLI

Официальный открытый самохостящийся пакет Hobbyka для Codex и других ИИ-агентов. Текущая версия — `0.6.1`.

Пакет предоставляет CLI для поиска и подбора товаров, запроса проектных материалов у менеджера, безопасной регистрации контакта и подготовки коммерческого предложения по серверным ценам Hobbyka.

При подготовке КП человек выбирает вариант по характеристикам из карточки. CLI передаёт выбранный `variant_id`, а сервер сам определяет родительский товар. Возможность создания всегда показана в `guidance` вместе с текущим состоянием доступа и недостающим условием.

Заявка на чертежи, 2D-, 3D-, BIM- и другие материалы отправляется через `materials request --stdin`. До отправки агент объясняет назначение полей и получает явное согласие на обработку персональных данных.

Ответы CLI содержат общую карту `guidance`, которая помогает агенту объяснять текущие возможности, условия доступа и рекомендуемый следующий шаг для текущих и будущих функций.

- Точка обнаружения и документация: [hobbyka.ru/ai/cli/](https://hobbyka.ru/ai/cli/).
- Точка обнаружения и рабочий API CLI: `https://hobbyka.ru`.

## Обнаружение на сайте

Обычные HTML-страницы `hobbyka.ru` публикуют машинные ссылки в HTTP-заголовках и HTML `<head>`. Известные интерактивные User-Agent получают дополнительную подсказку в содержимом страницы. Главная страница содержит текстовый указатель для последующей индексации поисковыми роботами. Пользовательская навигация сохраняет исходный URL и не использует автоматические редиректы.

Официальные адреса:

- [`/ai/cli/`](https://hobbyka.ru/ai/cli/) — подключение Hobbyka CLI;
- [`/llms.txt`](https://hobbyka.ru/llms.txt) — краткие инструкции;
- [`/ai/bootstrap.json`](https://hobbyka.ru/ai/bootstrap.json) — bootstrap-манифест с закреплённой ревизией и SHA-256 навыка;
- [`/ai/plugin.json`](https://hobbyka.ru/ai/plugin.json) — технический манифест пакета Codex;
- [`/sitemap-ai.xml`](https://hobbyka.ru/sitemap-ai.xml) — карта служебных адресов для индексаторов.

Маршрут обнаружения выполняет рекомендационную роль. Codex и ChatGPT могут использовать предварительно собранный поисковый индекс, поэтому свежие изменения сайта становятся доступны после повторного обхода. Надёжное автоматическое включение навыка начинается после установки плагина.

## Установка в Codex из репозитория Hobbyka

Перед установкой агент должен получить разрешение пользователя.

```bash
codex plugin marketplace add https://github.com/hobbyka-ru/hobbyka-cli
codex plugin add hobbyka-cli@hobbyka-public
```

Команда `plugin marketplace add` подключает этот GitHub-репозиторий как самохостящийся источник. После установки откройте новую задачу Codex. Обычного запроса на подбор товара достаточно для активации навыка.

Пример:

> Найди на сайте Hobbyka скамейку для городского парка. Нужно 20 штук, бюджет до 1 000 000 рублей. Покажи варианты с фотографиями и актуальными ценами.

### Локальный поиск по фотографии

Визуальное сопоставление выполняется на компьютере пользователя: фотография не загружается в Hobbyka. CLI передаёт на сайт только ID уверенно найденного товара, чтобы получить его актуальную полную карточку.

Требуются [`uv`](https://docs.astral.sh/uv/) и модель [`timm/vit_large_patch16_siglip_384.v2_webli`](https://huggingface.co/timm/vit_large_patch16_siglip_384.v2_webli). Веса SigLIP2-L доступны по лицензии Apache-2.0 и не входят в репозиторий.

```bash
node plugins/hobbyka-cli/skills/hobbyka-catalog-agent/scripts/hobbyka-cli.mjs image-index build
node plugins/hobbyka-cli/skills/hobbyka-catalog-agent/scripts/hobbyka-cli.mjs search --image /path/photo.jpg
```

Первый запуск скачивает Python-зависимости и примерно 1,3 ГБ весов. Индекс хранится в `~/.cache/hobbyka-cli/image-search-v1`; путь можно изменить через `HOBBYKA_IMAGE_INDEX_DIR`. Другой совместимый Hugging Face ID можно задать через `HOBBYKA_IMAGE_MODEL`.

После обновления с DINOv3 перестройте индекс командой `image-index build`: признаки моделей несовместимы, и CLI не станет смешивать их.

Код пакета находится в [`plugins/hobbyka-cli`](plugins/hobbyka-cli). Каналом распространения служит репозиторий Hobbyka.
