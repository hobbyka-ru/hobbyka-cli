# Hobbyka CLI

Официальный открытый самохостящийся пакет Hobbyka для Codex и других ИИ-агентов. Пакет предоставляет CLI для поиска и подбора товаров, безопасной регистрации контакта и подготовки коммерческого предложения по серверным ценам Hobbyka.

Рабочая публичная среда: [new.hobbyka.ru/ai/](https://new.hobbyka.ru/ai/).

## Обнаружение на сайте

Если агент действительно открывает страницу `new.hobbyka.ru`, сайт направляет известные пользовательские User-Agent ИИ в раздел `/ai/` и публикует машинные ссылки в HTTP-заголовках и HTML `<head>`:

- [`/llms.txt`](https://new.hobbyka.ru/llms.txt) — краткие инструкции;
- [`/ai/bootstrap.json`](https://new.hobbyka.ru/ai/bootstrap.json) — канонический bootstrap-манифест с закреплённой ревизией и SHA-256 навыка;
- [`/ai/plugin.json`](https://new.hobbyka.ru/ai/plugin.json) — технический манифест пакета Codex.

Это не публичный каталог и не автоматическая установка. Универсального стандарта, который обязывает любого агента проверять эти адреса, нет: агент должен сначала открыть домен, а перед установкой получить согласие пользователя.

## Установка в Codex из репозитория Hobbyka

Перед установкой агент должен получить разрешение пользователя.

```bash
codex plugin marketplace add mmasterkov/hobbyka-cli
codex plugin add hobbyka-cli@hobbyka-public
```

Команда `plugin marketplace add` здесь только подключает этот GitHub-репозиторий как самохостящийся источник. Публикация в общем каталоге плагинов не требуется.

После установки откройте новую задачу Codex. Пользователь может сформулировать обычный запрос на подбор товара; навык направит агента в Hobbyka CLI и запретит прямую работу с API или MCP.

Пример без упоминания CLI:

> Найди на сайте Hobbyka скамейку для городского парка. Нужно 20 штук, бюджет до 1 000 000 рублей. Покажи варианты с фотографиями и актуальными ценами.

Произвольный пользователь должен один раз подключить репозиторий и установить пакет. Метаданные сайта не устанавливают код автоматически.

## Разработка

```bash
npm run check
```

Код пакета находится в [`plugins/hobbyka-cli`](plugins/hobbyka-cli). Формат совместим с плагинами Codex, но источником и каналом распространения остаётся репозиторий Hobbyka.
